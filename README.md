#### Student: Reuben Benson
#### Allocated Supervisor: Nathan Clarke


## Project Vision

Small and micro businesses in the UK have consistently low levels of security awareness and cybersecurity measures when compared to medium and large organisations.

The limited security awareness of smaller businesses highlights the need for a more accessible, affordable SOC for organisations that cannot afford an internal IT security team or external SOC services.

This project aims to develop a user-friendly SOC targeted at smaller businesses that lack cybersecurity awareness and protection.

## Objectives
- Provide businesses with substantial security coverage, clear action points and easy-to-understand guidance.
- Aim to use Cyber Essentials, ISO standards, NIST Cybersecurity Framework and CIS Controls as benchmarks.
- Aim to incorporate an LLM to support businesses and give clear advice and feedback on implementation.
- Aim to incorporate different, tailored recommendations for businesses.
